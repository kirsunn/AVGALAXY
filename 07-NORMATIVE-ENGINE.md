# Нормативный движок

## 1. Задача

Нормативный движок применяет правила к зафиксированному snapshot аватара и формирует проверяемые результаты.

## 2. AVSPUTNIK

AVSPUTNIK — подключаемый модуль знаний или правил. Он содержит:

- стабильные ID правил;
- человеческие формулировки;
- формальные или исполняемые проверки;
- severity;
- применимость;
- ссылки на источники;
- версию и digest.

## 3. Типы правил

| Тип | Назначение |
|---|---|
| NORM | Нормативное требование |
| DEP | Зависимость и каскад |
| CHECK | Проверка значения или структуры |
| DERIVED | Производный расчёт |

## 4. Результат проверки

```json
{
  "finding_id": "find-001",
  "rule_id": "NORM-001",
  "entity_ref": "wall-123@gen:3",
  "snapshot_ref": "snap-001",
  "verdict": "fail",
  "severity": "required",
  "expected": ">= 0.9 m",
  "observed": null,
  "evidence_ids": [],
  "ruleset_version": "spu-001@1.2.0"
}
```

## 5. Запрещённые действия

- Подстановка нормативного порога как факта.
- Обнуление объёма или стоимости при отсутствии данных.
- Смешивание `unknown` и `fail`.
- Изменение snapshot при проверке.
- Применение правила без версии и источника.
