# AVGALAXY — one-pager

## Проблема

Нормативные проверки в BIM (площади, зоны, жильё) либо ручные, либо «чёрный ящик». Нет явного следа: *какая геометрия*, *какой критерий*, *какой snapshot*, *кто решил*.

## Решение (коротко)

**AVGALAXY** — контур: модель → явный `geometry_basis` → sealed snapshot → criterion → finding → **human decision**.  
Маппинг IFC/bSDD/глоссарий — кандидаты, не молчаливые истины. Норматив — пакет документов, не один СП.
