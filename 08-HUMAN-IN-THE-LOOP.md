# Человек в контуре

## 1. Принцип

AVGALAXY не является автономным проектировщиком. Система предлагает, проверяет и готовит решения; человек утверждает критичные изменения.

## 2. Уровни автономии

| Уровень | Значение |
|---|---|
| `SUGGEST` | Система предлагает вариант |
| `AUTO_SAFE` | Ограниченное безопасное действие по политике |
| `ESCALATE` | Конфликт или риск передаётся человеку |

## 3. Роли

| Роль | Зона ответственности |
|---|---|
| Картограф | Семантика таблиц, кандидаты связей |
| Инспектор | Согласованность и конфликты |
| Эксперт | Подтверждение неоднозначных решений |
| Регистратор | Реестры и артефакты |
| Адаптатор | Профили извлечения данных |
| Оператор | Прямые изменения аватара |

## 4. Решение

Любое критичное изменение фиксируется как decision:

```json
{
  "decision_id": "dec-207",
  "subject": "wall-123@gen:3",
  "action": "approve_rebirth",
  "basis": "NORM-001",
  "actor": "human:kirill",
  "evidence_ids": ["ev-118"]
}
```

## 5. Правило

Система не применяет изменение без разрешения, если оно влияет на нормативный статус, стоимость, геометрию или историю объекта.
