# ADR-002: Форматная лестница IFC5 → IFCA → AVIFC

Статус: proposed  
Дата: 2026-10-22

## Решение

1. IFC5 — внешний стандарт и основа для геометрии, свойств, GUID и топологии.
2. IFCA — исследовательский формат на основе IFC5 и ШАСЧ.
3. AVIFC — продуктовый файловый формат аватара.
4. AV-сущности сначала проверяются в IFCA.
5. В AVIFC попадают только утверждённые конструкции.
6. IFC5 не изменяется и не заменяется.

## Последствия

- Исследования не ломают продукт.
- Продуктовый формат остаётся управляемым.
- Совместимость с IFC5 сохраняется через явные маппинги.
