# Форматы: IFC5, IFCA, AVIFC

## 1. Лестница форматов

```text
IFC5  →  IFCA  →  AVIFC
```

| Формат | Статус | Назначение |
|---|---|---|
| IFC5 | Внешний стандарт | База: геометрия, свойства, GUID, топология |
| IFCA | Исследовательский | Эксперименты, маппинги, ШАСЧ |
| AVIFC | Продуктовый | Хранение и перенос состояния аватара |

## 2. IFC5

IFC5 остаётся неизменным внешним стандартом. Система читает IFC5, сохраняет его как Raw и связывает AV-сущности с IFC5-элементами по GUID.

## 3. IFCA

IFCA — исследовательский формат для:

- проверки AV-иерархии;
- экспериментальных маппингов;
- интеграции со ШАСЧ;
- проверки правил и обмена.

Из IFCA в AVIFC попадают только проверенные и утверждённые конструкции.

## 4. AVIFC

AVIFC — файловий формат аватара. Он содержит или ссылается на:

- AV-сущности;
- поколения;
- lifecycle events;
- snapshot-ссылки;
- enriched overlay;
- доказательства;
- решения;
- служебный манифест.

## 5. Правило promotion

```text
IFCA-конструкция → проверка → утверждение → AVIFC
```

Без явного promotion исследовательская конструкция не становится продуктовой.
