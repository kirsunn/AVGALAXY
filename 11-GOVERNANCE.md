# Управление документацией

## 1. Принципы

- Один термин — одно значение.
- Изменение концепции фиксируется в ADR.
- Устаревший документ не удаляется, а получает статус `superseded`.
- Каждый документ имеет версию, статус и владельца.
- Исследовательские материалы не смешиваются с продуктовыми.

## 2. Статусы документов

| Статус | Значение |
|---|---|
| `draft` | Черновик |
| `proposed` | Предложен к ревью |
| `accepted` | Принят |
| `deprecated` | Устарел |
| `superseded` | Заменён другим документом |

## 3. ADR

Архитектурное решение фиксируется в ADR, если оно:

- меняет модель данных;
- меняет формат AVIFC;
- меняет правила хранения;
- меняет AV-иерархию;
- вводит или запрещает опасную операцию.

## 4. Миграция

Старый документ при переносе получает одну из меток:

- `adopt` — принять;
- `rewrite` — переписать;
- `split` — разделить;
- `archive` — архивировать;
- `reject` — отклонить.
