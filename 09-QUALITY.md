# Качество, тестирование и приёмка

## 1. Принцип

Каждое утверждение системы должно быть проверяемым. Описание без теста не считается реализацией.

## 2. Уровни тестов

| Уровень | Что проверяется |
|---|---|
| Schema | Корректность AVIFC и AV-сущностей |
| Unit | Отдельные правила и функции |
| Integration | Поток IFC5 → AVIFC → проверка |
| Scenario | Сквозной кейс с решением человека |
| Regression | Отсутствие опасных действий |

## 3. Обязательные проверки

- Уникальность `av_id`.
- Разрешимость ссылок.
- Соответствие AVIFC-схеме.
- Сохранность snapshot.
- Отсутствие подмены факта порогом.
- Отсутствие обнуления неизвестных значений.
- Корректность перерождения.
- Полнота провенанса.

## 4. Definition of Done

- Есть тест или явная пометка об его отсутствии.
- Все ссылки разрешаются.
- Версии зафиксированы.
- История сохраняется.
- Решения отделены от предложений.
- Опасные операции заблокированы.
