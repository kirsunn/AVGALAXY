# Словарь терминов (продукт)

Язык команды (канон, витрина, кухня, Drive) — отдельно: [TEAM-GLOSSARY.md](TEAM-GLOSSARY.md).

| Термин | Определение |
|---|---|
| Аватар | Цифровая копия физического объекта; контейнер графовой БД, AVIFC-файла и служебных файлов |
| Физический объект | Реальный объект: здание, сооружение, дорога, элемент инфраструктуры |
| Сущность | Элемент модели с идентичностью, атрибутами, связями и провенансом |
| Поколение | Версия сущности, возникающая при существенном изменении |
| Перерождение | Переход сущности в новое поколение с сохранением идентичности |
| Жизненный цикл | Управляемая последовательность состояний и событий |
| AVGALAXY | Верхняя сущность глобального контура |
| AVSTAR | Сущность домена или звезды |
| AVPLANET | Сущность рабочего контура проекта |
| AVSPUTNIK | Подключаемый модуль знаний или правил |
| IFC5 | Внешний открытый стандарт BIM-данных |
| IFCA | Исследовательский формат на базе IFC5 и ШАСЧ |
| AVIFC | Продуктовый файловый формат аватара |
| Графовая БД | Хранилище сущностей, связей, состояний и ЖЦ внутри аватара |
| Raw | Неизменяемый исходный артефакт |
| Snapshot | Зафиксированное состояние, доступное только для чтения |
| Enriched Overlay | Производный слой с результатами обогащения и каскадов |
| Evidence | Доказательство с ссылкой на источник и локатором |
| Decision | Решение человека или уполномоченного процесса |
| Finding | Результат проверки правила |
| Superseded | Статус замещённой версии |
| ZERO-BUS | Инвариант: исходные данные не перезаписываются |
