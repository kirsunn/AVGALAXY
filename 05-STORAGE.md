# Принципы хранения

## 1. Состав аватара

```text
AVATAR/
├── graph/          # графовая БД
├── avifc/          # AVIFC-файлы
├── service/        # манифест, конфигурации, журналы
├── raw/            # неизменяемые источники
├── snapshots/      # зафиксированные состояния
└── overlays/       # обогащённые и производные слои
```

## 2. Инварианты

1. Raw не изменяется.
2. Snapshot только читается.
3. Производные значения живут в overlay.
4. Каждое значение имеет провенанс.
5. Каждая версия имеет идентификатор и hash.
6. История сохраняется.
7. `unknown` не превращается в `0`.
8. Нормативный порог не подменяет факт.

## 3. Разделение значений

| Тип | Значение |
|---|---|
| `observed` | Фактически наблюдаемое значение |
| `required_limit` | Нормативный порог |
| `assumed` | Предположение |
| `derived` | Расчётное или производное значение |

## 4. Версионирование

- AVIFC-файл версионируется.
- Snapshot имеет идентификатор и hash.
- AVSPUTNIK имеет версию и digest.
- Правило имеет стабильный ID и версию.
- Изменение создаёт новую версию, а не переписывает старую.

## 5. Хранение связей

Связь хранит:

- идентификатор;
- тип отношения;
- ссылки на концы;
- доказательства;
- статусы review, consistency и freshness.
